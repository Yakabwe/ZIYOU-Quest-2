# ZIYOU QUEST 2.2

## Règles
- Récupérer la clé avant d'ouvrir le coffre.
- Éviter lasers, drones et pics.
- À chaque vie perdue, le chien tombe et cesse de suivre.
- Il faut revenir le toucher pour le remettre sur pattes.
- Arriver au coffre sans le chien : aucun code, message d'échec, puis RESTART manuel.
- Arriver avec le chien mais en plus de 10 secondes : aucun code, défi de finir en 10 secondes ou moins, puis RESTART manuel.
- Arriver avec le chien en 10 secondes ou moins : code secret `perch'industry`.
- En victoire parfaite : boutons RESTART et QUITTER LE JEU.

## Contrôles
- Flèches
- ZQSD
- WASD
- Joystick analogique tactile sur mobile

Le jeu reste autonome dans un seul `index.html`.
